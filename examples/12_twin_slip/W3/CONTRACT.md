# W3 execution contract

Scope: A0 configuration/native response, A1 isolated FR emission, B0 existing-loop propagation, minimal B1 ideal nonpenetrating contact and prepared threader. No four-thickness collective evolution, no VCoNi material qualification, no main merge.

Branch: codex/w3-source-contact. W1 production scripts/data and existing native pin patch are retained unchanged. New production code and evidence live inside W3; native dependencies use the existing verified VM build.

Ordering: A0 must PASS before dynamic A1/B runs. Every native command/configuration/output is retained. Failure states are saved. Source daughter rings may only arise from native topology, never from initialization after time zero or artificial injection.

Material scope: effective isotropic FCC benchmark, explicit friction/drag parameters. VCoNi elastic substitution alone cannot qualify an alloy constitutive model.

Contact: unilateral, glide-compatible ideal I0 constraint. Tangential motion and release are tested. Accepted integration, collision, topology and remesh states must be admissible; an illegal state is rejected or causes FAIL, never silently accepted. Finite-barrier fail-closed behavior in W1 is preserved.

Source benchmark: first 240 nm / 80 nm, independently bracket emission stress, then demonstrate at least three native detachments with retained anchor and lineage evidence. Sensitivities are incremental 120/240/480 nm and 40/80/160 nm, not a blind full factorial campaign.

Final causal question: for byte-identical initial arrays and identical constitutive/mobility/numerical settings, does adding the second wall change an already-existing dislocation's propagation? Both second-wall increment and two-wall nonadditivity are reported. Prepared threaders are labeled prepared states, not spontaneous structures.

Resource stops: per-case physical-time/step/wall bounds are explicit in each frozen config. Exceeding a bound is not a physical PASS. No experiment is left running at final closeout.
